Controller event constants. Events are organized by category and follow a consistent naming pattern: - Core events (READY, ERROR, DESTROYED) - Device events (DEV_*) - Channel events (CH_*) - System events (SYS_*) - Patch events (PATCH_*)

Properties:
Name Type Description

DESTROYED string Emitted when controller is destroyed

CH_CC_RECV string Emitted when receiving control change
CH_NOTE_ON_SEND string Emitted when sending note on
CH_NOTE_ON_RECV string Emitted when receiving note on
CH_NOTE_OFF_SEND string Emitted when sending note off
CH_NOTE_OFF_RECV string Emitted when receiving note off

Examples
// Listen for controller ready
midi.on(midi.READY, (controller) => {
  console.log("MIDI ready!");
});
// Listen for CC messages (both send and receive)
midi.on(midi.CH_CC_SEND, ({ cc, value, channel }) => {
  console.log(`Sent CC ${cc}: ${value} on channel ${channel}`);
});

midi.on(midi.CH_CC_RECV, ({ cc, value, channel }) => {
  console.log(`Received CC ${cc}: ${value} on channel ${channel}`);
});
// Listen for device connections
midi.on(midi.DEV_OUT_CONNECTED, (device) => {
  console.log(`Output connected: ${device.name}`);
});
